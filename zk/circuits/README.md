# Circuits — v0.4

Empty. Source circuits (`.circom` / `.nr`) land here once the framework decision in `docs/zk.md`
is made. Compiled artifacts (`.r1cs`, `.zkey`) are build outputs and are not committed.

The Solidity verifier is generated (`snarkjs zkey export solidityverifier` / `nargo codegen-verifier`)
into `contracts/src/zk/`. Never hand-written.
